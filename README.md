## 📌 Project Overview
A mini relational database project developed using **MySQL** to demonstrate database design, normalization, SQL querying, reporting, and basic database optimization.

This project simulates a university student management system where students enroll in courses taught by faculty members.

## ✨ Features
- Normalized relational schema (6 tables)
- Primary & Foreign Keys
- CRUD-ready structure
- 30 SQL queries
- JOINs
- GROUP BY & HAVING
- Aggregate functions
- Subqueries
- Views
- Stored Procedure
- Index
- Reporting queries

## 🛠 Tech Stack

- SQL

## 🗄 Database Schema

Departments → Faculty
Faculty → Courses
Students ↔ Courses (Enrollments)
Enrollments → Attendance
